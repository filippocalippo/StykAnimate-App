# Clipboard wire

The shared clipboard (`src/shared-clipboard.mjs`) writes what the editor copied to the operating system's clipboard and reads it back in another window as the versioned `STYKCBW1` binary format of `src/clipboard-wire.mjs`. What it carries (figures, timeline frames, camera motion, drawing pixels) is the editor's clipboard fields as plain data; the engine session keeps the clipboards and the interface mirrors them (`docs/engine/editing.md`, "Clipboards"). Packets own transferable `ArrayBuffer` allocations of at most 256 KiB. The desktop shell keeps them as opaque bytes (`desktop/shared-clipboard.cjs`); the receiver acknowledges a packet only after it has been decoded into unpublished staging, and cancellation, a changed document, malformed data and a failed transfer discard that staging.

Float64 runs preserve JavaScript numeric values without Pivot float32 rounding. Bounded Latin-1 or UTF16 runs preserve exact strings, including unpaired surrogate code units. A bounded dictionary shares repeated property names. Plain and null-prototype records, property order, explicit undefined, negative zero, sparse-array holes and enumerable custom array fields survive the wire. Own `__proto__` properties are defined as data properties. Cycles and unsupported object types are rejected.

The encoder uses an explicit traversal stack and writes directly into the packet. Its default packing target is 2 ms; the decoder yields within a packet against a 4 ms target. These targets are not hard latency limits: garbage collection, native property enumeration and operating-system scheduling may take longer.

The shared clipboard admits 256 MiB of actual encoded input and, independently, an expanded-data estimate of 512 MiB. Arrays, strings, property slots and dictionary names are charged before the corresponding allocations; declared lengths, nesting and dictionary capacity have additional limits. The estimate is not measured JavaScript heap residency.

`tests/clipboard-wire.test.mjs` covers exact field and string fidelity, owned transfers, malformed and truncated tokens, dictionary saturation, resource bounds, ordering and cancellation; `tests/shared-clipboard.test.mjs` runs the whole path between two engine-owned editors.
