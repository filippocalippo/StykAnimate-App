# Baseline of the JavaScript engine (before the Rust port)

The app at `96ebce85`, the commit the Rust engine port started from
([`docs/RUST-ENGINE-PORT.md`](../RUST-ENGINE-PORT.md), section 5, has the protocol).
Generated by `node scripts/engine-bench-summary.mjs baseline-0` from
`artifacts/engine-rust/bench/baseline-0/` (kept locally: `artifacts/` is not versioned) and
pasted below unchanged; the final report
compares the engine against these numbers with the same driver.

- **When:** 2026-10-02 18:30 to 2026-10-03 00:34, three rounds
  (`scripts/engine-bench-matrix.sh baseline-0 tmp/baseline-worktree`).
- **Machine:** AMD Ryzen 5 5500 (12 threads), 61 GiB, Linux; the same machine the port
  is developed on.
- **Cells:** the median of the three runs, with their range. Each run waits for the
  1-minute load to fall below 3, for at most 10 minutes; the four runs that started on a
  busy machine are listed at the end. The port's own builds and two subagents were
  working on this machine during rounds 2 and 3, so a run that started idle may have
  had company before it ended: treat the ranges, not only the medians, as the
  measurement.
- **Window:** 1440×900, default settings, light theme, English; a fresh profile per run.
