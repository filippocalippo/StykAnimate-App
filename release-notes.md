# StykAnimate 0.5.0

More time for your next animation.

- Installed Windows copies now download updates in the background and let you restart when you’re ready.
- A new welcome screen shows what’s changed in your installed release, even when you’re offline.
- Support StykAnimate’s development from the welcome screen or the export window.

StykAnimate is completely free. [Support development on Ko-fi](https://ko-fi.com/Q5Q41WY7QC).

Install the **Setup** version for automatic updates. Portable copies require manual updates.
